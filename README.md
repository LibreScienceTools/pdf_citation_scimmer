
# Motivation
This project helps scientists to manage their references more efficiently. For example, I used to download literature as PDFs and saved them centrally in an directory. At another time, I write on a paper and needed to cite several articles previously saved as PDFs. To do this, I used Citavi or JabRef and passed the DOI to automatically add it to my library or I had to type it in manually.

This was a time consuming task because I had to do it for each individual PDF. With this PDF citation scimmer, I provide a solution for this problem. You take your PDFs and place it in a directory it in a directory associated with your paper and let the program run. The program walks through every PDF in this directory and extraxt metadata like DOI, author, etc. These metadata ist stored in an .bib file, which can be imported to Citavi, JabRef, or Zetero.
